# IncreaseDifficultyMod has moved to DeepRunOverhaul

**This package is now just a pointer.** The mod is called **DeepRunOverhaul** from 0.10.15 on, a name that says
what it does: a run-long overhaul that gets harder the deeper you go.

- Updating this package installs **WhitesLove-DeepRunOverhaul** for you. It contains no plugin of its own, so
  nothing runs twice.
- Your settings, perks, upgrades and costumes carry over: the plugin GUID (`com.kubai.increasehardmod`) and the
  config file stay the same.
- After the update you can uninstall IncreaseDifficultyMod and keep only DeepRunOverhaul.
