# IncreaseDifficultyMod 0.10.11

A clean-up release: two old troubleshooting tools are gone.

## Removed

- **Photon HUD**: an off-by-default overlay that tested the connection to Photon's region servers. That testing could itself stop the game from picking a region, so normal players had nothing to gain from it.
- **Diagnostics** settings (`DisablePatches`, `DisableRuntimeObjects`): switches that turned off almost the whole mod. They were added to find the old "stuck loading online" bug, which is fixed.

**Server Info** stays: the top-left panel with server region, ping, room code and player count. It only displays what the game already knows and opens no connections of its own.

Old values for the removed settings in your config file are simply ignored.

The plugin now reports its real version in the BepInEx log (it said 0.10.8 since that release).

Checked by the build, not yet in a live game.

## From 0.10.10

- Every mod gun spends exactly one battery bar per shot, and the bars show the shots left.
- New Wide View perk (Recon, Vision): +5 degrees field of view per level, up to +15.
- The host's log names what hurts the mod's monsters, to trace the Naga Queen's unexplained damage.
