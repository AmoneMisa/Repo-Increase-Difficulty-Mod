# IncreaseDifficultyMod 0.8.5

- **New: trade-off skills.** Every skill tree page except Contracts has three new rows, TRADE-OFFS I, II and III. Each trade-off makes you better at one thing and worse at another, and you hold one per row on each page:
  - **How they open:** a row unlocks once you have spent enough points in that page's normal perks (about 30%, 60% and 85% of the page), and rows II and III also need a pick in the row below. A locked trade-off shows how far you are, for example "8/12".
  - **Cost:** row I costs 1 point, row II 2 and row III 3. The whole tree is now 213 points.
  - **Swapping:** the new **RESET TRADE-OFFS** button ($5K, shop or truck only) refunds only your trade-offs. **REFUND ALL** still refunds everything.
  - **Combat:** Gunner's Focus, Bruiser · Glass Cannon, Overdrive · Sharpshooter, Berserker.
  - **Arsenal:** Hand Cannon, Cart Commander · Lingering Toxins, Quick Shock · Executioner, Overkill.
  - **Survival:** Thick Skin, Sprinter · Juggernaut, Daredevil, Second Heart · Last Stand, Ghost Runner.
  - **Recon:** Floodlight, Spotlight · Scout, Echo Ping · Oracle, Hunter's Eye.
  - **Utility:** Tinkerer, Drone Jockey · Medic's Oath, Fortune Seeker · Overclock, Salvager.
  Hover a trade-off in the tree to see its exact upside and downside. When the game is set to Russian, trade-off names and descriptions are shown in Russian. The reset price is in the config under "Skill Tree" (`TradeOffResetCostK`).
- Version 0.8.5. Players in a lobby should all run 0.8.5.

Not yet checked in-game: the trade-off skills, especially Executioner, Echo Ping, Oracle, Last Stand and Hunter's Eye, which use new game hooks. The project builds without warnings and the skill tree, network and collection tests pass.
