# DeepRunOverhaul 0.11.0

A new level: **Fable Realm**, with its own puzzle room and twenty-one valuables found only there.

### Fable Realm

- **A new level in the run's level list**: 32 rooms built for the mod (3 start rooms, 14 rooms, 4 passages, 5 dead ends, 6 extraction rooms) in a storybook setting: a gingerbread village, a forest, a giant's castle.
- **The giant bean puzzle**: at most one special room per level. Five coloured beans are hidden in other rooms; put each bean on the plate of its colour and the beanstalk grows, with a **Golden Egg** ($250,000) on its crown. The host decides everything, late joiners catch up.
- The rooms ship as `fablerealm.bundle` next to the plugin DLL. Every player needs the mod with the same `Modules/FableRealm` setting.

- **Red Basket**: carried upright it keeps its five pies. Tipped on its side or upside down they fall out one by one, and each lost pie takes part of the value with it.

- **Red Ribbon**: if you would die while holding it, the ribbon takes the blow once. You survive, return to the truck, and the ribbon is used up.

### Settings

- `Modules/FableRealm` (on by default): adds the level. Every player needs the same value; takes effect on restart.
- `Fable Realm/VanillaStartRoom` (off): start the level from a Manor start room instead of its own. Every player needs the same value; takes effect on restart.
- `Fable Realm/ForceLevel` (off, host): every level of the run is Fable Realm.
