# 0.6.3 code audit — 2026-11-01

## Fixed findings

- **P1: malformed network packets.** Timer, ping, vote, repair and shield-drain
  callbacks now validate packet shapes, types and finite numbers before mutation.
- **P1: missing sender checks.** Authoritative timer/vote/repair state requires the
  host; ballots cannot impersonate another actor. Shield drain must be positive,
  target a defence drone and originate from a covered player. Negative drain can
  no longer charge arbitrary batteries.
- **P2: wasted Death Protection charges.** Match native hit rejection and saving
  grace, and apply protection after shields have reduced the final damage.
- **P2: regeneration scaling/cap errors.** Apply healing multipliers before
  fractional accumulation, avoid a second scaling pass and respect the HP cap.
- **P2: incomplete sprint reduction.** Scale the full native sprint deduction,
  including the sprint-speed surcharge. Accumulate fractions too small for one
  float deduction. Jump/slide costs and authored base fields remain native.
- **P2: stale Charge Efficiency.** Existing stations pick up team purchases and
  config changes before charging; each station retains its own authored rate.
- **P2: ineffective battery purchases.** Stop at the effective +100% bonus or the
  lower configured level cap.
- **P2: invalid Black Market purchases.** Reject nonexistent/composite modifier
  IDs and unknown catalogue kinds before spending currency.
- **P2: incoming pings while disabled.** Remote markers respect the ping toggle.

## Validation

The audited build passed 813 controlled Unity assertions and 61 controlled
network assertions. All 122 Harmony targets resolved against the installed game;
89 embedded resources matched their source hashes. Native sprint IL and the
shield/Death Protection prefix order were checked. Build: zero warnings/errors.

The portable [network suite](../../tests/NetworkTests/README.md) is included in the
repository. The broader Unity fixture uses local game/engine references and is
not distributed with the mod. These checks are not a live multiplayer or Proton
certification.

## Open issues and follow-ups

- **Confirmed visual mismatch:** HUD text copies native font settings but the
  independent overlay clears glow and does not inherit native blur/chromatic
  processing automatically. Diagnostic fallbacks use Unity GUI fonts. Follow
  [AGENTS.md](../../AGENTS.md) and the supplied reference; this is not fixed by
  adopting the font family alone.
- **Potential lifecycle issue, not reproduced live:** delayed AutoRevive has no
  captured level/scene token. Test transitions during the death wait.
- **Potential lifecycle issue, not reproduced live:** Loot Cash-In resets its
  once-per-level latch on a non-level frame. Test direct level-to-level restarts.

Version stays 0.6.3; the plugin GUID, config filename and saved upgrade IDs remain
compatible. No proprietary game assemblies or extracted game fonts are included.
