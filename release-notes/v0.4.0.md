# Increase Hard Mod 0.4.0

Big update: compatibility with the latest R.E.P.O. build (v0.5.0), a round results board, eleven new shop items with their own models, animations and sounds, and a tidier config.

## What's new

**Compatibility**
- Works with the current game build and REPOLib 4.3.0. Fixed the startup crash caused by overloaded game methods (this also fixes Late Join and the runtime objects not being created).
- Charge Efficiency truck upgrade ported to the renamed charging-station field.
- Patches are now applied one by one: a single patch broken by a future game update can no longer stop the whole mod from loading.

**Round results (MVP / OOPS CHAMP)**
- After each level: per-player loot hauled, loot broken, deaths and revives, plus team totals, an MVP and an OOPS CHAMP. Host-recorded and synced; hauled loot counts only on a successful extraction. `F7` dismisses / recalls it.

**New shop items** (each can be switched off individually, see `Modules` in the config)
- Drones: **Ghost** (walk through a valuable, not counted in extraction), **Silencer** (target gets very quiet), **Link Drone Set A + B** (physical cable between two objects, reel it in), **Repair** (restores lost value; 25,000 per full battery).
- Gear: **Defence Orb** (protects loot), **Defence Drone** (absorbs 350 damage for a player), **Protection Orb** (-25% damage), **Poison Crossbow** (7 damage + 125 over 15 s, poisoned monsters hunt players), **Decoy Grenade** (lures monsters for 5 s), **Pulse Ice Pistol** (freeze, no knockback), **Sticky Pistol** (pull monsters/objects).
- Original models, textures, animations and sounds are embedded in the DLL; poison and frost effects show on monsters for everyone.

**Config**
- New **Modules** section at the top of the config with every on/off switch. Values from the old sections are carried over automatically the first time.
- Per-stat difficulty scaling switches (enemy health, damage, speed, respawn, quota).

**README** now documents every upgrade and item.

## Install / update
- Needs BepInEx 5.4.21 and **REPOLib 4.3.0**. Optional: REPOConfig 1.2.7 + MenuLib 2.6.0 (REPOModding).
- **Every player must run the same version** (the shop items and effects are synchronised).
- Replace the old `IncreaseHardMod.dll`; do not keep two copies of the mod installed.
- Not tested in a live multiplayer session yet; please report anything odd with your `LogOutput.log`.

# Increase Hard Mod 0.4.0 (по-русски)

Большое обновление: совместимость с последней сборкой R.E.P.O. (v0.5.0), таблица итогов раунда, одиннадцать новых предметов магазина со своими моделями, анимациями и звуками и более удобный конфиг.

**Совместимость:** работает с текущей версией игры и REPOLib 4.3.0; исправлен вылет при запуске из-за перегруженных методов игры (вместе с ним чинятся Late Join и создание рабочих объектов); апгрейд Charge Efficiency переведён на переименованное поле; патчи применяются по одному, поэтому один сломанный патч больше не остановит весь мод.

**Итоги раунда (MVP / OOPS CHAMP):** по каждому игроку добытое, разбитое, смерти и воскрешения, итоги команды, MVP и OOPS CHAMP. `F7` скрывает и возвращает таблицу.

**Новые предметы:** дроны Ghost, Silencer, Link (A + B), Repair; снаряжение Defence Orb, Defence Drone, Protection Orb, Poison Crossbow, Decoy Grenade, Pulse Ice Pistol, Sticky Pistol. У каждого свой переключатель.

**Конфиг:** новая секция **Modules** вверху со всеми переключателями (значения из старых секций переносятся сами), переключатели роста сложности по каждой характеристике.

**Установка:** BepInEx 5.4.21 и **REPOLib 4.3.0**; мод одной версии должен стоять у **всех** игроков; замени старый `IncreaseHardMod.dll`, не держи две копии. В живой мультиплеерной игре пока не проверено.
