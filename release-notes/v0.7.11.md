# IncreaseDifficultyMod 0.7.11

- **Battery upgrades now show on the bar.** Bullet, Laser and Tranq Gun Extra Shots add one battery segment per extra shot, so a fully charged upgraded gun shows more bars. Drone Battery Life adds segments in proportion to its bonus (+50% means 50% more bars). The charge percentage is kept when bars are added. Previously the upgrades worked, but the bar looked the same as without them.
- **Guns now use the right Extra Shots upgrade.** Pulse Pistol, Boltzap and the Wizard Staff now use Laser Gun Extra Shots, like the Photon Blaster. The Ice and Poison pistols (the Poison one is the crossbow), the Sticky Pistol and the Net Launcher now use Tranq Gun Extra Shots. Before, all of these used the Bullet upgrade, although the README said the mod's pistols used Tranq. Owned levels are per upgrade, so a level bought as Bullet does not move to these guns. Spritz, a single-use item, is no longer affected by any Extra Shots upgrade.
- Version 0.7.11.

Not yet checked in a running game. The project builds without warnings.

## Русский

- **Улучшения батареи теперь видны на шкале.** Bullet, Laser и Tranq Gun Extra Shots добавляют по одному делению батареи на каждый дополнительный выстрел, поэтому у полностью заряженного улучшенного оружия больше делений. Drone Battery Life добавляет деления пропорционально бонусу (+50% — на 50% больше делений). Процент заряда при этом сохраняется. Раньше улучшения работали, но шкала выглядела так же, как без них.
- **Оружие теперь использует правильное улучшение Extra Shots.** Pulse Pistol, Boltzap и Wizard Staff теперь используют Laser Gun Extra Shots, как Photon Blaster. Ледяной и ядовитый пистолеты (ядовитый — это арбалет), липкий пистолет и Net Launcher теперь используют Tranq Gun Extra Shots. Раньше всё это оружие использовало улучшение для пуль, хотя в README было написано, что пистолеты мода используют транквилизатор. Уровни принадлежат конкретному улучшению, поэтому уровень, купленный как Bullet, на это оружие не переходит. На Spritz, одноразовый предмет, улучшения Extra Shots больше не действуют.
- Версия 0.7.11.

Ещё не проверено в игре. Проект собирается без предупреждений.
