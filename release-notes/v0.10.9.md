# IncreaseDifficultyMod 0.10.9

A quieter danger warning from courier pets, the normal view behind the Wide cart, and a fix for "lobby unavailable" mid-run.

## Joining mid-run

- After a short Steam connection hiccup, Steam can hand the lobby to another player. The host then could no longer reopen it, and new players got "lobby unavailable" for the rest of the session. A guest who ends up owning the lobby now hands it straight back to the host, so the lobby reopens on its own within a few seconds.
- If the host still cannot reopen the Steam lobby, the host's log now says why (who owns the lobby and whether the host is still in it). If it keeps happening, return to the main menu and host again; the run checkpoint is kept.

## Wide cart

- Pushing the Wide cart no longer raises your camera: you keep the normal first-person height. The flame cart still lifts the view while you push it.

## Courier pets

- A pet now chimes **once per monster** instead of repeating its alarm every few seconds while the monster stays near. The red "!" over its head still shows for as long as the danger lasts.
- When several pets sense the same monster, only one of them chimes. A knocked-out pet does not use up the warning for that monster.
- The alarm itself is softer: two gentle rising notes at a lower volume instead of three sharp chirps.
- A monster that wanders off and comes back later in the same level is not announced again (the "!" still appears). Every new level starts fresh.

All changes are checked by a build only, not yet in a live game.

## From 0.10.8

A smaller download with the same content and the same look as 0.10.7: costume shading textures are kept as greyscale, every texture is packed at the strongest lossless setting, and courier pets no longer ship a second texture for their surface relief. The package is over a quarter smaller than 0.10.7 (158 MB -> 116 MB).
