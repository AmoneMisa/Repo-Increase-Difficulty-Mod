# IncreaseDifficultyMod 0.6.0

## English

### New inventory upgrade

- **Inventory Slot** is now available in the normal shop: **+1 slot per level**, up to **7 total slots** (3 base + 4 upgrades).
- Connected the finished Inventory wrapper and separate transparent inventory icon.
- Extra slots use native item icons, battery indicators and inventory actions. Contents are saved/restored across level and truck transitions.
- Default extra-slot keys: **4–7**, configurable under **Inventory Slots**. Module switch: **Modules / InventorySlots**. Base price: **Player Upgrades / InventorySlotBasePrice**.
- Upgraded guests can use their extra slots even if the host has only three.

### Upgrades and shared truck progression

- Capped custom upgrades cannot be consumed at maximum level; the card remains available for another player. One-time ping upgrades cap at **1**, Map Suite at **10**, Inventory Slot at **4** levels. Other upgrades respect their declared/configured caps. A spent Death Protection charge can be replenished.
- Fixed saved upgrade levels becoming disconnected from REPOLib ownership checks.
- **Heal Power**, **Charge Efficiency** and **Loot Cash-In** share the actual upgrade level with the whole team, including late joiners. The effect remains after the buyer leaves.
- Fixed Loot Cash-In's dollar-to-K conversion to prevent excessive payouts.
- Fixed internal `IHM_…` upgrade names in Tab.
- Connected prepared wrapper atlases and separate UI icons. Ping Anywhere, Ping Info and Pin have distinct artwork. Native pack geometry, UVs, animation and collision are preserved.

### Interface

- Full-screen **Black Market** and **level results**, with readable native REPO typography.
- Results close on shop entry. **F7** recalls/dismisses them, **Esc** closes, **PgUp/PgDn** changes pages for large teams.
- Removed forced bold weight, extra letter spacing and artificial thick outlines; labels inherit the game HUD’s Teko font asset, style and spacing.
- Fixed invisible/black text inherited from masked HUD materials and clipped text bounds.
- Restored server information to the **top left**.
- Shopping list has no backdrop; names, quantities, prices and totals are visible with explicit K units.
- Compact transparent map-vote HUD. **F6** hides/shows it without cancelling the vote.
- Vote using **NumPad 1–6 or mouse clicks**. Main-row number keys remain inventory controls; inventory actions take priority when bindings overlap.
- Unstuck messages have no backdrop and appear above the inventory.
- Shop modifiers use subdued unboxed titles. Open the map/Tab for the full effect explanation, including Field Hospital's health-pack discount and crystal surcharge.

### Pings, weapons and models

- Item pings now trace the actual silhouette with a **2-pixel contour and a downward arrow**, without filling the item. Floor markers use a hollow ring and an arrow. Fixed projection from low-resolution render textures to the displayed screen rectangle.
- Fixed local/network echo producing two pings from one press.
- **Ping Anywhere or Pin remains required for floor/wall markers.** Ping Info adds information only.
- Sticky Pistol casts a visible cable with a short coiled launch and follows the target. Suppressed ordinary bullet, tracer and muzzle-flash effects for this weapon; added softer spool/latch sounds.
- Pulling remains host-controlled, respects strength/mass limits and protects pulled loot from damage.
- Fixed custom-model material selection when textureless Fresnel/VFX materials precede the body material, so embedded weapon textures can be applied correctly.

### Additional fixes

- Fixed printed upgrade atlases resolving to similarly named `Icon_Upgrade_…` UI renders, which caused cropped artwork and black faces.
- Compact server status avoids native health/energy; voting follows the actual money display. Modifier names align below quota counters without the technical SURPRISE/SHOP prefixes; Tab also explains level economy events.
- Restored self-hover for active custom drones after removing donor effect scripts; added the same native timed hover overrides to custom shield orbs. Host-only, inactive/stowed devices stop refreshing the overrides.
- Fixed cloned inventory slots inheriting the donor's animation coordinates and overlapping old slots. Slots remain in one row during native SemiUI animations.

### Reliability and compatibility

- Includes the startup round-statistics fix, save protection/backups and local audio/voice recovery from the 0.5.10 update.
- Existing plugin GUID, config filename and upgrade IDs stay compatible. Extra inventory slots add their own save data.
- Models, wrappers, textures, icons and sounds are embedded in the DLL.

### Installation / update

**Thunderstore Mod Manager / r2modman:** install/import `IncreaseDifficultyMod-0.6.0.zip`; ensure **BepInExPack** and **REPOLib** are installed. Optional **REPOConfig + MenuLib** expose settings in-game. Restart and launch modded.

**Manual:** close the game, install BepInEx 5 and REPOLib, then copy `plugins/IncreaseDifficultyMod` from the ZIP into `BepInEx/plugins/` in the game folder or active manager profile. Keep **one active DLL**: remove the previous `IncreaseHardMod.dll` / older installation. Keep `BepInEx/config/com.kubai.increasehardmod.cfg`.

All lobby members must update to **0.6.0** and fully restart. UI, inventory layout, upgrade caps, shared levels and weapon physics were checked in a Unity Editor fixture. Live multiplayer and Proton still need play-testing.

## Русский

### Новое улучшение инвентаря

- **Inventory Slot** добавлен в обычный магазин: **+1 слот за уровень**, максимум **7 слотов всего** (3 базовых + 4 улучшения).
- Подключены готовая обёртка Inventory и отдельная прозрачная иконка инвентаря.
- Дополнительные ячейки используют штатные иконки, индикаторы батареи и действия инвентаря. Содержимое сохраняется при переходах между уровнем и машиной.
- Клавиши по умолчанию — **4–7**, настраиваются в **Inventory Slots**. Переключатель модуля — **Modules / InventorySlots**, базовая цена — **Player Upgrades / InventorySlotBasePrice**.
- Гость с улучшением может пользоваться своими дополнительными слотами, даже если у хоста их только три.

### Улучшения и общий прогресс машины

- Улучшения с капом больше нельзя съесть на максимальном уровне; предмет остаётся доступен другому игроку. Одноразовые улучшения пинга имеют кап **1**, Map Suite — **10**, Inventory Slot — **4** уровня. Остальные соблюдают объявленные/настроенные лимиты. Израсходованный заряд Death Protection можно восполнить.
- Исправлено расхождение сохранённых уровней с проверками владения в REPOLib.
- **Heal Power**, **Charge Efficiency** и **Loot Cash-In** передают фактический уровень всей команде, включая поздно подключившихся. Выход покупателя не отменяет общий эффект.
- Исправлен перевод долларов в K у Loot Cash-In, из-за которого выплата могла быть завышена.
- Исправлены внутренние названия `IHM_…` в Tab.
- Подключены подготовленные атласы обёрток и отдельные UI-иконки. У Ping Anywhere, Ping Info и Pin разное оформление. Ванильная геометрия упаковок, UV, анимации и коллизии сохранены.

### Интерфейс

- Полноэкранные **Black Market** и **итоги уровня** с читаемым родным шрифтом REPO.
- Итоги закрываются при входе в магазин. **F7** возвращает/скрывает их, **Esc** закрывает, **PgUp/PgDn** переключает страницы большой команды.
- Убраны принудительная жирность, разрядка и искусственная толстая обводка. Текст наследует игровой ассет Teko, начертание и интервалы HUD.
- Исправлены чёрный/невидимый текст из-за масок HUD и обрезание текста.
- Статус сервера возвращён **влево вверх**.
- Корзина выводится без подложки: видны названия, количество, цены и итог с явным обозначением K.
- Голосование стало компактным и без подложки. **F6** скрывает/показывает HUD без отмены голосования.
- Голосование — **NumPad 1–6 или мышь**. Цифры основного ряда остаются инвентарю; при совпадении назначений приоритет у действия инвентаря.
- Сообщения Unstuck перенесены над инвентарём и показываются без подложки.
- Название события магазина приглушено и без подложки. Карта/Tab показывает полное объяснение эффекта, включая скидку на аптечки и наценку на кристаллы у Field Hospital.

### Пинги, оружие и модели

- Пинг предмета повторяет реальный силуэт: **контур 2 пикселя и стрелка сверху**, без заливки. На полу показываются кольцо и стрелка. Исправлен перевод координат низкоразрешённой render texture в фактическую область экрана.
- Убрано сетевое эхо, создававшее две метки от одного нажатия.
- **Для пола и стен по-прежнему нужен Ping Anywhere или Pin.** Ping Info добавляет только информацию.
- Sticky Pistol выпускает видимый трос с коротким витым запуском и следованием за целью. Для него отключены обычная пуля, трассер и вспышка; добавлены мягкие звуки катушки и захвата.
- Сохранены притягивание под управлением хоста, ограничения силы/массы и защита притягиваемого лута от повреждений.
- Исправлен выбор материалов новых моделей при наличии Fresnel/VFX-материалов без текстур перед материалом корпуса: встроенные текстуры оружия могут применяться корректно.

### Дополнительные исправления

- Исправлен выбор UI-иконки `Icon_Upgrade_…` вместо атласа упаковки: рисунки больше не обрезаются из-за неверной текстуры и не дают чёрных граней.
- Компактный статус сервера обходит здоровье/энергию; голосование следует за областью денег. Названия модификаторов выровнены под счётчиком целей без служебных SURPRISE/SHOP; Tab объясняет и экономику уровня.
- Возвращено зависание активных кастомных дронов после удаления донорских эффектов. Защитные сферы используют те же временные переопределения физики. Управляет хост; выключенные/убранные устройства не поддерживают зависание.
- Исправлено наследование координат анимации донорской ячейки: дополнительные слоты больше не накладываются на прежние и остаются одной строкой при анимациях SemiUI.

### Надёжность и совместимость

- Включены исправление запуска статистики, защита сохранений/бэкапы и локальное восстановление звука/голоса из обновления 0.5.10.
- GUID, имя конфига и прежние ID улучшений сохранены. Дополнительные слоты добавляют собственные данные сохранения.
- Модели, обёртки, текстуры, иконки и звуки встроены в DLL.

### Установка / обновление

**Thunderstore Mod Manager / r2modman:** установите/импортируйте `IncreaseDifficultyMod-0.6.0.zip`; проверьте наличие **BepInExPack** и **REPOLib**. Для настроек в игре опционально установите **REPOConfig + MenuLib**. Перезапустите игру через modded-запуск.

**Вручную:** закройте игру, установите BepInEx 5 и REPOLib, затем скопируйте `plugins/IncreaseDifficultyMod` из ZIP в `BepInEx/plugins/` игры или активного профиля менеджера. Оставьте **одну активную DLL**: удалите старую `IncreaseHardMod.dll` / прежнюю установку. Сохраните `BepInEx/config/com.kubai.increasehardmod.cfg`.

Всем участникам лобби нужно обновиться до **0.6.0** и полностью перезапустить игру. UI, раскладка слотов, капы, общие уровни и физика оружия проверены в стенде Unity Editor. Живой мультиплеер и Proton ещё требуют игрового теста.
