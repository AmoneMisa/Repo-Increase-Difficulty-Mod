# IncreaseDifficultyMod 0.7.3

- Late Join now repairs Steam admission independently of Photon room openness, including public rooms. Only the Steam owner publishes the actual Photon room name, region and game version; friends-only sessions stay friends-only.
- Reopen admission after level generation completes, with the existing periodic safety check retained. Use the current game's Photon room-opening API to reset its persistent-object close handshake.
- Friends/invite/Steam lobby-link connections wait up to eight seconds for missing Steam routing metadata before the native connection checks run. Leaving the lobby or receiving a different invite cancels that wait. Native password/version validation and genuinely closed-lobby errors remain intact.
- Fix the Unity 6 `MissingMethodException: int UnityEngine.SceneManagement.Scene.get_handle()` in player freezing by comparing Scene values through their stable equality operator.
- Poison crossbow bolts now explicitly set direct player damage from the poison direct-hit setting (default 7) and clear inherited instant-kill flags. They no longer retain the donor projectile's player damage; poison ticks remain separate.
- Restore modifier names, Tab descriptions and Map Suite statistics by putting their native TMP objects on the HUD canvas's UI layer. The native overlay camera excludes the Default layer previously used by these objects.
- Right-hand HUD order: quota amount, quota count, Map Suite statistics, modifier names. Map Suite and modifier descriptions appear together on Tab, with independent pagination when needed. Preserve native font/material rendering and avoid text backplates.
- Include the current collection weight, lighting and animation changes in the same 0.7.3 package.

## Investigation and validation

The two supplied logs identify the loaded plugin as **0.7.2**, with the same DLL MVID. They show the freeze exception, but do not contain the joining player's failed connection. The exact cause of the screenshot therefore remains unconfirmed; this release fixes the admission and metadata defects found in the code.

Compared the admission flow with [Rebateman/LateJoin](https://github.com/Rebateman/LateJoin/blob/main/LateJoin/Entry.cs), [L.A.T.E](https://github.com/NilaierMusic/L.A.T.E/blob/main/src/Patches.cs), and the native Steam invite entry point used by [RepoSteamIdJoin](https://github.com/bricks04/RepoSteamIdJoin/blob/main/SteamManagerPatches.cs). Implemented against the installed game's current `SteamLobbyManager` and Photon APIs; no old mod's cache-clearing implementation was transplanted.

Local regression command: `dotnet run --project tests/LateJoinTests/LateJoinTests.csproj -c Release`.
The fixture exercises production admission and metadata-wait code with simulated Steam/Photon state. It does not establish successful multiplayer joining in a running game.

Live validation still required on two Steam accounts: enter via friends and `steam://joinlobby/3241660/<lobby-id>/<host-id>` in the truck, shop and an active level; repeat after changing scenes and restarting a lobby. Confirm password/version rejection, player spawn and synchronized run state. Use the Steam **lobby** ID, not the host's personal Steam ID or a public Photon room name. Install the updated DLL on the host and joining client, restart the game, and check `Loading [IncreaseDifficultyMod 0.7.3]` in each log.

Regression fixtures passed: 29 Late Join checks, 97 network checks, 8 poison damage checks and 56 HUD checks. HUD checks cover the native UI layer, the requested order, simultaneous Map Suite/descriptions, paging and several aspect ratios. These fixtures do not certify visual effects or native glow in a running game. An in-game comparison against `art/references/hud-text-style.png` remains required.
