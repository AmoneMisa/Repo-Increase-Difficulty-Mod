# Maneki-neko — новая геометрия для согласования

Статус: **внешний вид согласован пользователем 4 ноября 2026**. Это архив статического предпросмотра. Анимированная интегрированная версия находится в [maneki-integrated-14](../maneki-integrated-14/README.md).

Работа выполнена
по приложенной фотографии; геометрия предыдущих вариантов v11/v13 не использована.
Исходное задание относилось к 0.7.2; интеграция выполнена в текущем проекте 0.7.4. Ниже сохранено описание стадии первоначального предпросмотра.

## Файлы

- `maneki_review.blend` — редактируемая сцена Blender 5.2.1: модель, материалы,
  упакованные текстуры, камера, освещение и отдельная поднятая лапа.
- `maneki_review.glb` — самостоятельный GLB с материалами и встроенными текстурами.
  **Это статический экспорт для согласования; анимация будет добавлена после одобрения.**
- `maneki_review.obj`, `maneki_review.mtl`, `textures/` — OBJ и его зависимости.
  Передавать вместе, сохраняя структуру папок. OBJ не хранит анимацию; вид бликов
  может отличаться, поскольку MTL не воспроизводит весь PBR-материал Blender.
- `maneki_front.png`, `maneki_three_quarter.png` — реальные рендеры Cycles этой модели.
- `reimport_glb.png`, `reimport_obj.png` — рендеры после обратного импорта.
- `geometry_stats.json`, `validation.json` — размеры, статистика и результаты проверок.

Сетка: около 35 тысяч треугольников; точное значение записано в статистике.
Предварительный размер: ширина 1,055 м, глубина 0,668 м, высота 1,567 м.
Это авторский рабочий масштаб: сравнение с машинкой Sunstone ещё не выполнено.
Начало координат находится на основании и по центру собственных горизонтальных
габаритов. Ось поднятой лапы предварительная; соединение в движении не утверждено.

Основные объёмы построены по контурам: сидящий корпус со слитыми переходами к
асимметричным лапам, широкая голова с интегрированными ушами и отдельная изогнутая
поднятая лапа. Глаза, усы, нос, отметины и красная роспись ушей находятся в текстуре,
а не в выпуклых линиях. Красный ошейник и золотые украшения — отдельная геометрия.
Глубина и тыльная сторона восстановлены предположительно: на исходной фотографии
виден только один ракурс. Точность художественного сходства остаётся на согласовании.

## Что проверено

`tools/validate_maneki14.py` действительно открывает BLEND, заново импортирует GLB
и OBJ и проверяет конечные координаты, UV, отсутствие вырожденных полигонов,
замкнутость поверхностей после склейки UV-швов и положительный ориентированный объём.
Сравниваются число треугольников и мировые габариты с допуском 0,1 мм; проверяется
загрузка всех трёх текстур. Результаты фиксируются только после завершения проверок.
Это проверки статического ассета, а не доказательство визуального сходства или
правильной работы предмета в R.E.P.O.

## После согласования формы

1. Сверить масштаб с реальной машинкой Sunstone, сохранить собственные габариты.
2. Уточнить плечевой шарнир и сделать постоянный плавный цикл вперёд-назад,
   проверить все фазы, отсутствие щелей и пересечений с головой. Записать цикл в GLB.
3. Экспортировать утверждённый меш в существующий формат `ValuableVisuals`.
   Связать лапу и её коллайдер с одним pivot. Исключить декоративные детали
   из набора отдельных физических коробок; подобрать корпусные коллайдеры.
4. Использовать уже имеющийся общий источник `PhotonNetwork.Time`, проверить
   одинаковую фазу у host/client и при позднем входе. Кнопка запуска не требуется.
5. Сохранить ограничения каталога: Museum и Headman Manor, 6,5 кг, $12 000–16 000,
   хрупкость. Подготовить отдельные фарфоровые удары/разрушение: сейчас используется
   общий стеклянный звук, он не подтверждён как подходящий.
6. Рассчитать собственный центр массы и полный объём движения лапы для размещения,
   заменить фиксированный запас глубины из `ValuableLayout`. Не брать размеры вазы.
7. Выполнить сборку с `DeployToGame=false`, подходящие Unity-проверки и отдельно
   перечислить остающиеся проверки игрового забега. Автоматическая установка запрещена.

Изучены: `InteractiveValuables`, `ValuableVisuals`, `ValuableArtInstance`,
`ValuableLayout`, `CollectionCatalog`, `CollectionSpawnPools`, `ValuableFoley`,
`ManekiMotion` и описание Unity fixture. Сборка и Unity fixture пока не запускались:
новый ассет ещё не подключён, их успешность не проверила бы эту модель в игре.

## Воспроизведение

Из корня проекта:

```powershell
python tools/maneki14_paint.py
& 'C:/Program Files/Blender Foundation/Blender 5.2/blender.exe' --background --factory-startup --python tools/build_maneki14.py
& 'C:/Program Files/Blender Foundation/Blender 5.2/blender.exe' --background --factory-startup --python tools/validate_maneki14.py
```

Генератор использует Pillow и локальный CJK-шрифт только для растеризации 福 на
медальоне; файл шрифта не включён в поставку. Игровые шрифты не извлекались.
Редактирование `.blend` возможно напрямую; повторная генерация перезаписывает
только эту папку ассета, поэтому ручные изменения следует сохранить отдельно.
